# Cut over to the protocol layer (2026-11-06)

This repository was cut over on 2026-11-06, per Mere's
`design_docs/mere_docs/implementation_strategy/2026-11-06_cycle_breaks_plan.md`
(rulings D7, D8 and D9). Before the cut it held the first Graphshell, written
before the 2026-07-23 repo consolidation. It now holds only the protocol layer.

## What the repository held before

- A Cargo workspace of five crates: `graphshell-protocol`, `graphshell-client`,
  `graphshell-endpoint`, `graphshell-stdio` and `graphshell` (a native
  presentation host), at version 0.0.1 under `MIT OR Apache-2.0`.
- `docs/`: the G1, G2 and G4 receipts (`2026-07-22_g1_loopback_presentation_receipt.md`,
  `2026-07-22_g2_diff_resume_receipt.md`, `2026-07-22_g4_cross_product_receipt.md`
  and `docs/receipts/`).
- `LICENSE-MIT` and `LICENSE-APACHE`.
- 1,263 commits and 8 branches (`agent/add-dual-license-files`,
  `agent/publish-projection-host`, `copilot/add-feature-gated-overlay-backend`,
  `copilot/adopt-unified-omnibar`, `gpui`, `iced-wgpu-bump`, `main`,
  `webrender-wgpu-branch`).

The repository was archived on 2026-07-23 when Graphshell moved into
`merely-made/mere`, was unarchived and transferred from `mark-ik/graphshell` on
2026-11-06, and was cut over the same day.

`7676823cc0f7733ea70898d94916e3ccd9cb1192` ("Archived: moved in the 2026-07-23

## What replaced it

The host/guest contract crates that were in Mere, with their history:
`chirograph`, `hest`, `sceno`, `scenotime`, `script-wire`, `script-witgen`,
`graphshell-endpoint` (its default surface and the one WIT world) and
`graphshell-client`. Each was exported with its Mere history (see the README) and
merged in, so `git log` on a moved crate reaches back into Mere. The old
`graphshell-protocol` was renamed `chirograph` on 2026-08-14; the old Graphshell
presentation host is the reference host that lives in Mere (`ports/graphshell`),
above this layer.

Old licences did not carry over: the moved crates are MPL-2.0 and the old
`MIT OR Apache-2.0` files described code that is no longer here, so they were
removed in the cut-over commit and remain in history.
